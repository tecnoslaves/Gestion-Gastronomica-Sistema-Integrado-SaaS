## 🚀 Características Principales

Este sistema de punto de venta (POS) y gestión operativa está diseñado para optimizar los tiempos y recursos del local:

*   **📱 Pedidos Autónomos:** Interfaz amigable para que el cliente pueda realizar su pedido de forma independiente y directa.
*   **📦 Gestión de Inventario Inteligente:** Descuento matemático y automático de ingredientes en tiempo real a medida que se registran las ventas.
*   **🔒 Seguridad y Respaldo:** Bases de datos encriptadas y alojadas en nuestro cloud server para garantizar la integridad de la información del negocio.
*   **⚡ Arquitectura Web:** Acceso desde cualquier dispositivo con navegador web, sin necesidad de instalaciones locales ni hardware específico.

## 🛠️ Sobre el Desarrollo

**Proyecto SACUR** es una solución de software propietario orientada a la eficiencia del rubro gastronómico. La arquitectura backend se ejecuta de forma segura en servidores dedicados, garantizando alta disponibilidad y procesamiento de datos en tiempo real.
